# Worksheet sample texts

Sample texts for the reading worksheets (`/es/fichas/`, `/ca/fitxes/`, `/en/worksheets/`), one file per language:

- [Español](es/README.md)
- [Català](ca/README.md)
- [English](en/README.md)

## Format

Each text is a level-2 heading (the worksheet title), an optional first list item with the age level, and the text. Blank lines separate paragraphs.

```markdown
## The cat who wanted to fly
- Level: Ages 6–7

Lola is a small grey cat.

Every morning, Lola watches the birds.
```

The same format is used by “Export my texts” and “Import texts” on the website, so an exported file can be added here as it is, and these files can be imported on the website.

## Adding texts

- Write original texts, or texts whose licence allows it. Name the source if it is not yours.
- Short sentences and familiar words for the youngest; one idea per paragraph.
- Keep each text to one A4 page at “Very large” size.
- Add the text in every language when you can.
