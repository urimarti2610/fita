# Security policy

fita runs entirely on your device: no servers, accounts or data collection. Security still matters: the extension runs on the pages you read, and the converter opens files you choose.

## Reporting a vulnerability

Please report it **privately**: [open a security advisory](https://github.com/urimarti2610/fita/security/advisories/new). Only maintainers can see it.

Include what you found, how to reproduce it, and which part is affected (extension, website, converter, core library). We will acknowledge it within a week and keep you informed until it is fixed. Please do not open a public issue for security problems.

## Supported versions

Only the latest release of the extension and the current website are supported.
